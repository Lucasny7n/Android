# Lucas Collection | Yamata Launcher

**13 fontes de catálogo de jogos (metadados e capas, sem arquivos de jogos).** Criadas em 06/11/2026.

## Importar

Yamata → Settings → Game Catalog Sources → + → cole a URL completa de **um catálogo** → OK. Repita para outras plataformas. Não cole estes arquivos em Download Sources.

## Fontes e créditos

- Yamata Launcher: https://github.com/Gr3gorywolf/Yamata-launcher
- Game Store Catalog (Ephellon): https://github.com/Ephellon/game-store-catalog
- Libretro Thumbnails: https://github.com/libretro-thumbnails/libretro-thumbnails
- x360db: https://github.com/xenia-manager/x360db

As imagens são acessadas nos servidores originais, onde podem deixar de existir. Marcas, logos e artes continuam pertencendo aos respectivos titulares. Nenhum arquivo executável ou ROM é incluído.
